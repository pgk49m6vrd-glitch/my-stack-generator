## 2024-05-18 - WCAG 1.4.1 Color-Based Error Indicators
**Learning:** Never rely solely on color to communicate information (like red text for an error message), as this violates WCAG 1.4.1 (Use of Color).
**Action:** Always pair color-based indicators with explicit icons (e.g., warning SVGs) and/or structural layout changes to ensure accessibility.
